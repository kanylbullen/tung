In the app

What it does

Works offline
Your log lives on your device. A basement gym with no signal is fine, and you need no account.
Last time, right there
Every set is filled in from your last session, set by set. Records and estimated 1RM are worked out while you train.
Phone, watch and web
An Android app, a Wear OS app that works without the phone, and a web app you can install. They sync through your server.
Your own server
Sync is optional. Use this server, or run your own with one Docker image and Postgres.
Ask your assistant
The server speaks MCP, so Claude and other assistants can log sets, read your history and suggest your next workout, with your permission.
Open source
The app and the server are AGPL-3.0. The exercise catalogue is open data under CC0.

Connect your assistant

In Claude Code you add the server with one line, then sign in when it asks:

claude mcp add --transport http tung https://tung.xuper.fun/mcp

Run your own

Clone the repository, fill in POSTGRES_PASSWORD and TUNG_PUBLIC_URL in .env, and start it:

git clone https://github.com/kanylbullen/tung.git
cd tung/deploy
cp .env.example .env
docker compose up -d
