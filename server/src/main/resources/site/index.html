A training log for the set you are about to do.

Tung shows what you lifted last time and fills in the next set for you. You change a number, tap Log set and rest. Everything else waits until after the workout.

Open the web app Source on GitHub

What it does

Works offline
Your log lives on your device. A basement gym with no signal is fine, and you need no account.
Last time, right there
Every set is filled in from your last session, set by set. Records and estimated 1RM are worked out while you train.
Phone, watch and web
An Android app, a Wear OS app that works without the phone, and this web app, which you can install. They sync through your server.
Your own server
Sync is optional. Use this server, or run your own with one Docker image and Postgres.
Ask your assistant
The server speaks MCP, so Claude and other assistants can log sets, read your history and suggest your next workout, with your permission.
Open source
The app and the server are AGPL-3.0. The exercise catalogue is open data under CC0.

Run your own

Clone the repository, set a database password in deploy/.env and start it:

cd tung/deploy
docker compose up -d
